# API

- `GET /api/kpis` — filtered KPI summary
- `GET /api/breakdown/{dimension}` — grouped metrics
- `GET /api/reports/{name}` — composed report
- `POST /api/snapshots` — persist report output
- `GET /api/snapshots` — historical snapshots
- `GET /api/export/{dimension}.csv` — downloadable grouped report
- `GET /healthz` — health
